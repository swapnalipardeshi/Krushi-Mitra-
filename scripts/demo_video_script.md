## 🎬 Post-Production Notes

### 🎵 Background Music
- Use royalty-free lo-fi or cinematic music (keep volume low under voiceover)
- Suggested: [Pixabay Free Music](https://pixabay.com/music/) or [Mixkit](https://mixkit.co/free-stock-music/)

### ✂️ Editing Tips
- Use **zoom-in** effects when showing specific UI elements (AI results, prices)
- Add **text overlays** for feature names during the montage section
- Use **smooth transitions** (crossfade/slide) between scenes — avoid hard cuts
- Add **subtle highlight boxes** or arrows to draw attention to key UI actions
- Consider adding **captions/subtitles** for accessibility

### 📐 Resolution & Format
- Record at **1080p (1920×1080)** minimum
- Export as **MP4, H.264 codec**
- Keep final file under **100 MB** if there's a submission size limit

### 🛠️ Recommended Tools
| Tool | Purpose |
